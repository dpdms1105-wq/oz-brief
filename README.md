# 오즈 공고봇 — 설치 안내

매일 아침 지원사업·업체공모를 찾아 **카카오톡 「나와의 채팅」**으로 보냅니다.
**노트북을 꺼도 돕니다.** GitHub 서버에서 실행됩니다. 비용 0원.

```
07:13 KST  GitHub Actions 자동 실행
   ↓  네이버 검색 API(웹·뉴스) 12개 키워드 + 기업마당
   ↓  오즈 적합도 점수화 → 🔴즉시 / 🟡검토 / ⬜참고  (채용·무관 건 자동 탈락)
   ↓  중복 제거 (이미 보고한 건 재발송 안 함)
   ↓  브리핑 웹페이지 생성 (GitHub Pages)
   ↓  카카오톡 리스트 메시지 발송 (상위 3건 + 전체보기 버튼)
```

> 🔴 **신규 0건이면 카톡을 보내지 않습니다.** 매일 오면 안 보게 되니까요.

# 설치

> 🟢 **초보자용 상세 안내는 같은 폴더의 `설치 따라하기.md`를 보십시오.**
> 클릭 하나까지 적혀 있고, 중간에 끊고 나중에 이어 할 수 있습니다.

| 단계 | 내용 | 시간 |
|:---:|:---|:---|
| 1 | GitHub 가입 + 저장소 `oz-brief` (Public) 생성 + 파일 업로드 | 10분 |
| 2 | Settings → Pages → `main` / `/docs` | 2분 |
| 3 | 네이버 개발자센터 → 검색 API → Client ID/Secret | 5분 |
| 4 | 카카오 디벨로퍼스 → REST 키 + 도메인 등록 + refresh_token | 15분 🔴 |
| 5 | GitHub Secrets 5개 등록 | 5분 |
| 6 | Actions → Run workflow → 카톡 확인 | 3분 |

### Secrets 5개

| 이름 | 값 |
|:---|:---|
| `NAVER_CLIENT_ID` | 네이버 Client ID |
| `NAVER_CLIENT_SECRET` | 네이버 Client Secret |
| `KAKAO_REST_KEY` | 카카오 REST API 키 |
| `KAKAO_REFRESH_TOKEN` | 카카오 refresh_token |
| `PAGES_URL` | `https://아이디.github.io/oz-brief` |
